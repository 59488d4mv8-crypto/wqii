# 弱势维度建议

## 一、如何识别弱势维度

对每位教师，在所有维度上计算其在团队中的分位。若某维度的 Min-Max 分数低于 0.4，即认为是该教师的弱势维度。

## 二、常见弱势维度与建议

| 弱势维度 | 建议 |
| --- | --- |
| avg_rating 低 | 主动收集学生反馈，针对性改进课程内容与讲解方式 |
| completion_rate 低 | 加强课程结构设计，设置学习提醒，拆分过大章节 |
| interaction_rate 低 | 增加随堂练习、提问环节、直播互动时间 |
| review_count 低 | 运营侧推动评价活动，设置评价奖励，引导学生留下评价 |

## 三、运营落地

- **Top 教师**：标杆学习对象，作为内部讲师培训案例
- **中等教师**：根据弱势维度制定个性化改进方案
- **垫底教师**：设置观察期，结合培训和课程内容整改
