# 用户画像概念

## 一、什么是用户画像

用户画像（User Persona / User Profile）是根据用户的人口统计学特征、行为数据、偏好等信息，将用户抽象成若干典型类型。

## 二、本项目使用的字段

| 字段 | 含义 |
| --- | --- |
| user_id | 用户 ID |
| age | 年龄 |
| gender | 性别（M/F） |
| city | 所在城市层级（一线城市/二线/三线/其他） |
| prefer_subject | 偏好学科（数据/编程/设计/商业/语言） |
| device | 设备（mobile/pc） |
| active_hour | 活跃小时（0-23） |
| session_count | 学习次数 |

## 三、典型画像类型

| 画像 | 定义 | 运营策略 |
| --- | --- | --- |
| **白天学习者** | active_hour 在 9:00-17:00 | 工作日推送学习任务、社群活动 |
| **夜猫子** | active_hour 在 22:00-次日 5:00 | 晚间直播课、夜读内容 |
| **周末集中学习者** | 学习频次较高且集中在周末 | 周末打包课程、短期训练营 |

## 四、分析思路

1. 按字段统计分布（饼图、柱状图）
2. 交叉分析（age 分组 × 偏好学科）
3. 规则划分三类典型画像
4. 生成运营策略矩阵
